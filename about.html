About This Project

Purpose

This repository exists to demonstrate a complete Git and GitHub workflow: initialising a local repository, committing changes, working on a branch, merging it back and publishing the result to GitHub.

Workflow Steps

  1. Initialise the repository and record the first commit.
  2. Update a page and commit the change.
  3. Create the feature branch and commit on it.
  4. Merge the branch into main.
  5. Add .gitignore and practise undoing a commit.
